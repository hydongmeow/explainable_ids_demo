# XAI-IDS

These Jupyter notebooks are designed as a tutorial and visual demonstration of the XAI usage for intrusion detection.

They serve as the supplementary materials of our survey paper:
*An Evolution of Explainable Intrusion Detection: From Statistical Foundations to Large Language Models*  

## Contents

### XAI_ inherent_explainability_examples

* X-Y Correlation
* Linear Regression
* Principal Component Analysis (PCA) 
* Machine Learning
    * Decision Tree
    * Support Vector Machines (SVMs)
    * k-Nearest Neighbours (kNN) 
    * Fuzzy Logic
